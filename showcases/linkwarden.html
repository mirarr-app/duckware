Linkwarden

Bookmarks that outlive the pages they point to.

A self-hosted collaborative vault to collect, read, annotate, and fully preserve the web — so link rot never erases what you meant to keep.

View on GitHub Launch demo Self-host docs

The problem

Useful pages disappear.

A bookmark is only a promise. Domains expire, redesigns wipe archives, and paywalls swallow essays you meant to revisit. Linkwarden treats every save as a preservation job — not a pointer you hope still works.

Ordinary bookmark managers store a URL and a title. When the original goes dark, so does your research trail. Linkwarden’s reason for existing is that gap: organize what you find and keep a recoverable copy under your control.

Optional Wayback Machine submission adds a public off-site snapshot when you want belt-and-suspenders archival — without forcing your library into someone else’s silo.

Triple seal

Preserve every save three ways.

On capture, Linkwarden seals the page as a screenshot, a PDF, and a single-file HTML archive — so you can browse, print, or re-read even after the live site is gone.

Read it later — keep it forever

Annotate inside the vault.

Linkwarden blends a calm reader view with archive reliability. Highlight passages, leave notes, and return months later — even if the original article has vanished from the open web.

Reader view

On building a library that does not trust the live web

The open web is generous and fragile at once. Saving a URL is optimism; saving the page itself is stewardship. Annotations turn a cold archive into a working notebook — highlights that still mean something when the source is gone.

Your server or theirs

Run it where you trust the disk.

Self-host with Docker when you want the vault on your own hardware, or start on Linkwarden Cloud if you’d rather skip ops and fund the project directly. Either path keeps the same idea: your bookmarks should survive the web’s memory holes.
